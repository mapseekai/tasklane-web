本版本将通信协议推进至 `v4`（当前最新版本已演进至 `v7`），新增了跨浏览器与 Node.js Worker 的 `File` / `Blob` 附件传输支持及独立的附件逻辑字节限额。

## 主要变化摘要

- **有界 `File` / `Blob` 附件表**：支持在协议包中直接传递最多 `256` 个 `Blob` 或 `File` 附件，并在浏览器与 Node.js `worker_threads` 两端完整保留 `File` 的 `name`、`type` 与 `lastModified` 元数据。
- **独立的每任务 `blobLimits`**：将文件附件的逻辑字节大小限制（`blobLimits.inputBytes` / `outputBytes`，默认 `0`）与内存缓冲区协议预算分开校验，要求非空附件必须显式声明上限。
- **补充文件分块与常驻 Session 指南**：提供基于 `Session` 的按范围文件分块读取示例、大型二进制数值缓存技巧以及常驻 `Session` 容量规划说明。
