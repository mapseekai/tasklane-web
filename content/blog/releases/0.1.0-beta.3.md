本版本将通信协议推进至 `v5`（当前最新版本已演进至 `v7`），引入了绑定 Worker 之前的受控异步输入准备阶段、结构化远端业务错误传递以及公共的分块结果迭代器。

## 主要变化摘要

- **受预算约束的异步输入准备（`enqueuePrepared`）**：允许在分配物理 Worker 之前，先在调用线程通过 `prepareAsync` 执行受 `maxPreparingTasks` 窗口与 `preparationScratchBytes` 约束的异步 I/O 读取。
- **结构化远端业务错误（`remoteError`）**：Worker 处理函数抛出的异常现在可保留有界的 `name`、`code`、`message`、`stack` 以及受深度和字节限制的 `details` 结构化元数据。
- **公共分块结果迭代器（`iterateResults`）**：正式从主包导出拉取式消费迭代器，自动保证在释放上一块 `ResultLease` 后再请求下一块，并提供确定性的游标与作用域关闭屏障。

## 原始记录

- Protocol v5: structured, bounded remote business error metadata.
- Budgeted asynchronous input preparation before Worker admission.
- Public result iteration with deterministic lease and cursor cleanup.
- Simplified task completion state and shared test/benchmark helpers.
