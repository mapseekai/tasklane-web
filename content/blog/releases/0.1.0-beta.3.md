异步输入准备、结构化远端错误和公共结果迭代。

## 主要变化

- 协议 v5 保留有界的远端业务错误元数据。
- 在 Worker 准入前支持受预算控制的异步输入准备。
- 提供公共结果迭代接口和确定性的租约、游标清理。

## 原始记录

以下内容保留 [tasklane CHANGELOG](https://github.com/mapseekai/tasklane/blob/b40ba606552c4b798ebb803528548151186b364b/CHANGELOG.md) 中此版本的原文，便于核对完整变化和兼容性。中文摘要用于阅读导航，详细历史以原始记录为准。

- Protocol v5: structured, bounded remote business error metadata.
- Budgeted asynchronous input preparation before Worker admission.
- Public result iteration with deterministic lease and cursor cleanup.
- Simplified task completion state and shared test/benchmark helpers.
