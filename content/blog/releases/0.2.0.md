`0.2.0` 是 tasklane 的首个正式版，运行时行为与 `0.2.0-beta.2` 相同，继续使用 Worker 协议 **v7**。从较早协议版本升级时，请同时更新主线程包与独立打包的 Worker。

## 主要变化摘要

- npm 的 `latest` 通道指向正式版，可用 `npm install @mapseekai/tasklane` 安装。
- npm 包加入项目 logo，README 链接到独立文档站，并补充了架构文档。

## 原始记录

以下内容保留 [tasklane CHANGELOG](https://github.com/mapseekai/tasklane/blob/e9a97a4d0eea921767f6baf5a8b34bd23ab8c4ef/CHANGELOG.md) 中此版本的英文原文：

- Promote 0.2.0-beta.2 to the first stable 0.2.0 release; no runtime behavior changes since beta.2.
- Publish the package on npm's latest channel and include the project logo in the package.
- Link the documentation site and expand architecture documentation.
