每份指南围绕一个具体问题。先确认资源与状态的所有者，再选择相应的操作入口。

- [异步输入准备](preparation/)：在取得额度后读取或组装输入。
- [取消与超时](cancellation/)：让用户取消与物理任务收尾保持一致。
- [文件与分块](files/)：为 File/Blob、分块结果和游标声明边界。
- [状态型计算](sessions/)：打开资源、缓存并等待 disposer。
- [资源调度与内存压力](resource-scheduling/)：配置预留、缩容与回收。
- [指标与故障诊断](diagnostics/)：定位预算、租约和 Worker 问题。
- [测试与验证](testing/)：为应用集成建立可重复的检查。
